# UWB 定半径圆弧跟随

`uwb_follow.arc_follow.enabled=true` 时，传统 `relative_imu` 跟随仅对后半平面的目标启用圆弧恢复。
使用校准并归一化后的船体偏角：`abs(bearingDeg)>90°` 才启用左右转弯圆与切线；
前方 180°（`-90° ≤ bearingDeg ≤ 90°`，包含左右边界）始终使用原来的跟随方法。
目标一进入前半平面就交回原跟随，不等待整段圆弧或切点退出确认，不继续绕圈。
交接时清除本次圆弧锁定，并把最近的推力、转向输出交给接手控制器的原有限速逻辑；
下一次目标进入后半平面时重新选侧。前方继续使用原跟随；大偏角时对组合减速系数保留低速下限，
消除原 55° 停进门限与 90° 圆弧分界之间的推进死区。低速参考不超过圆弧速度上限（默认 0.3 m/s）。

初始半径为 1.5 m，速度参考上限为 0.3 m/s；转弯曲率不超过 `1/radius_m`，接近切线时连续减小曲率。
后方目标也会持续前进转向，不经过旧的 55° 停进门限，不执行原地掉头或反向推进。

圆弧在首次进入跟随距离圆时截断；直线终点也提前保留跟随距离。Jetson 当前跟随距离为 0.5 m。
每次转弯开始时选侧，进入 `left_arc` 或 `right_arc` 状态并锁定本次转弯方向。
锁定期间每次更新仍重新计算目标、同侧圆心、切点、剩余路程和速度参考；不会冻结目标或切点。
生产控制在进入前半平面时优先交还原跟随；圆弧规划器自身的切点退出确认不会延迟这个交接。

圆弧执行中确需改向时，默认要求已锁定至少 2 s，另一侧路程优势严格超过
`max(side_switch_margin_m, side_switch_min_advantage_m)`（默认 1.5 m），
并连续保持至少 1.5 s、至少 8 帧新测量。任一条件中断就重新确认；改向后重新计算最短锁定时间。
原方向因目标进入转弯圆而无法作切线时，进入 `replan`，推进和转向参考归零；
输出归零、角速度稳定后，恢复的原侧或可行的新侧仍需连续确认至少 500 ms、5 帧，才恢复推进。
单帧路线失效不会立即换侧，恢复原路线也不会立即恢复推进。

所有确认均使用递增的 UWB `measurementUpdatedAt`，重复控制周期、预测点、过期或乱序测量不累加；
测量间隔超过 `uwb_timeout_ms` 也会中断连续确认。停车保持、目标/接收流身份变化、
控制时钟回退、导航更新长时间中断，以及未解锁、错误模式、UWB/IMU 失效，均清除原转弯状态。
船体测角使用独立的 `bearing_sign=-1, bearing_scale=1, bearing_offset_deg=0`，不再套用相机的角度缩放。

目标转速由船速与曲率计算，IMU 角速度用于闭环修正。前进和转向输出保留限速，
最终发送层继续限制差速不超过平均推力的 80%，从而使两侧电机输出均为正推或零。
未解锁、错误模式、UWB/IMU 超时、人工停止等原有保护仍有效；部署不自动开启跟随或解锁。
缺测时仍沿用现有的有界最后点处理，其时限和前向扇区保护不被圆弧模式放宽。

GPS 速度有效时用实测船速计算目标转速；GPS 不可用时使用现有推进模型估计速度，
`arcFollow.radiusEstimated=true`，不能视为已经实现精确的物理转弯半径。
`arcFollow.yawLimited=true` 表示同向推力或转向限幅限制了角速度控制，需要水面标定和半径验收。
软件几何回放不代替真实水面转弯半径测试。

前方大偏角与后方圆弧在 GPS 不可用时使用 `relative_min_effective_throttle_percent` 作为起转补偿，
经原有加速限速逐步给出，不再只依赖可能低于起转要求的速度模型小推力。
补偿随停止净空和速度参考降低；到达跟随距离、制动、预测点、重规划和传感器故障时不补偿。
GPS 实测速度闭环有效时由速度 PI 决定推力，不强加最小推力。
无 GPS 时 0.3 m/s 是模型参考，最小有效推力需要实船标定，不能据此声称实际航速已被测量。
运动状态中的 `frontTurn` 或 `arcFollow.minimumThrottlePercent` 显示低速转向与起转补偿是否生效。

运行参数见 `/api/uwb-follow/state` 的 `config.arcFollow`；运动状态中的 `arcFollow` 包含半径、
转向侧、剩余圆弧角度、圆心、切点、剩余路程和限幅状态，还包括
`state`、`lockedSide`、`transitionReason` 和 `transitionPending`（待确认事件、起始测量时刻与已确认帧数）。
受控重规划期间运动状态为 `status=replanning, reason=arc_replanning`，与跟随距离停车分开显示。

状态切换参数位于 `uwb_follow.arc_follow`；旧配置省略新增参数时使用以下默认值：

| 参数 | 默认值 | 含义 |
| --- | --- | --- |
| `arc_exit_distance_m` | 0.2 | 独立圆弧规划器的切点退出路程上限；生产模式先按 ±90° 交回原跟随 |
| `arc_exit_bearing_deg` | 6 | 独立圆弧规划器的切点退出偏角上限 |
| `arc_exit_yaw_rate_deg_s` | 3 | 重规划恢复及独立规划器切点退出时的角速度上限 |
| `straight_reentry_bearing_deg` | 12 | 独立圆弧规划器直线再入弧门限，必须大于退出偏角；生产前方阶段使用原跟随 |
| `transition_confirm_ms` | 500 | 重规划及独立规划器状态切换的连续确认时长 |
| `transition_confirm_samples` | 5 | 上述事件同时要求的新测量帧数 |
| `side_switch_min_advantage_m` | 1.5 | 圆弧中换侧所需的路线优势下限，与原 0.6 m 门限取较大值 |
| `side_switch_confirm_ms` | 1500 | 路线优势持续时长 |
| `side_switch_confirm_samples` | 8 | 路线优势持续的新测量帧数 |
| `side_min_lock_ms` | 2000 | 初次选侧或改向后，开始确认下一次优势换侧前的锁定时间 |
